# Banking Account Service

## What it does

Implements a simple banking account with operations to create accounts, deposit, withdraw, and check balance. Includes basic validation for withdrawal limits and input constraints.

## How to run tests

```bash
pytest
```

## How to test

Run the test suite in `week1_project2/tests` to verify account creation, deposits, withdrawals, and validation logic.

## What I learned

State management in simple classes, input validation, and writing tests with pytest.
